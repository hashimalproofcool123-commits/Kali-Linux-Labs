# Linux Commands

This section documents basic Linux commands with practical examples.

## 1. pwd

Displays the current working directory.

Example:
```bash
pwd
2. ls
Lists files and directories.
Example:ls
3. cd
Changes the current directory.
Example:cd Documents
4. mkdir
Creates a new directory.
Example:mkdir test-folder
5. touch
Creates an empty file.
Example:touch test.txt
6. cp
Copies files.
Example:cp test.txt backup.txt
7. mv
Moves or renames files.
Example:mv test.txt new-name.txt
8. rm
Removes files.
Example:rm test.txt
9. cat
Displays file contents.
Example:cat test.txt
10. whoami
Displays the current username.
Example:whoami
